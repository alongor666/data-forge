## 🔄 文档更新流程

### 添加新功能时

1. 更新代码实现
2. 更新相关核心文档（本目录）
3. 更新 [项目上下文.md](../项目上下文.md) 对应章节
4. 提交Git并注明文档更新

### 修改业务规范时

1. 更新 [处理规范.md](处理规范.md)
2. 更新 [项目上下文.md](../项目上下文.md) "数据处理规范"章节
3. 同步更新代码实现
4. 验证功能完整性

### 发布新版本时

1. 更新所有核心文档的版本号
2. 在 [项目上下文.md](../项目上下文.md) 添加版本记录
3. 更新根目录 README.md
4. 创建Git版本标签
