# 数据预处理器脚本规范 v2.2.0

## 📋 概述

本文档详细说明数据预处理器脚本的使用规范，包括输出要求、字段映射表和计算方法。本系统是一个基于Flask的Web应用程序，提供直观的用户界面和强大的数据处理能力。

**最新版本**: v2.2.0  
**更新时间**: 2025年1月29日  
**核心特性**: 用户指定周序号 + 本地文件夹存储 + 双重下载方式

---

## 🎯 核心功能

### 主要特性
- **智能字段映射**: 17个筛选维度字段的完整中英文映射
- **精确绝对值计算**: 9个绝对值字段的智能计算和单位转换
- **用户指定周序号**: 支持用户手动指定周次编号（1-53周）
- **双重存储机制**: 本地"处理后"文件夹 + 浏览器下载
- **实时数据处理**: Web界面实时上传和处理Excel文件
- **智能年度识别**: 从数据内容和文件名智能提取保单年度
- **完整数据验证**: 多层次数据质量检查和异常处理
- **标准化输出**: 统一的文件命名和数据格式规范

### 技术规范
- **Web框架**: Flask 3.1.2 + HTML5 + CSS3 + JavaScript
- **数据处理**: pandas 2.3.2 + numpy 2.3.3 + openpyxl 3.1.5
- **数据架构**: 17个筛选维度 + 9个绝对值字段 + week_number
- **字段命名**: 统一英文标准命名（signed_premium_yuan等）
- **单位标准**: 所有金额字段统一为"元"单位
- **计算原则**: 先聚合绝对值，再计算比率
- **存储方式**: 本地"处理后"文件夹 + 浏览器下载双重保障

### 核心输出文件

#### 1. 主数据文件
- **命名格式**: `YYYY保单第WW周变动成本明细表.csv`
- **存储位置**: 
  - 本地访问：`./处理后/` 文件夹
  - 浏览器下载：自动触发下载
- **编码格式**: UTF-8 with BOM（确保Excel正确显示中文）
- **数据结构**: 17个筛选维度字段 + 9个绝对值字段 + week_number字段
- **年度识别**: 智能从数据内容提取保单年度，文件名作为备选

#### 2. 周序号处理机制（v2.2.0新增）
- **用户指定优先**: 用户在Web界面指定的周序号（1-53）
- **文件名提取**: 支持多种格式（第XX周、周XX、WXX、week XX等）
- **默认值**: 未指定时使用40周作为默认值
- **验证机制**: 确保周序号在合理范围内（1-53）

#### 3. 双重下载方式
- **本地文件夹访问**: 
  - 路径：项目根目录下的"处理后"文件夹
  - 优势：永久保存，便于批量管理
  - 适用：需要长期保存或批量处理的场景
- **浏览器下载**:
  - 方式：处理完成后自动触发下载
  - 优势：即时获取，无需访问服务器文件系统
  - 适用：单次处理或远程访问的场景

## 🧮 8个绝对值字段计算方法

### 保费类字段（单位：元）

#### 1. 签单保费 (signed_premium_yuan)
- **计算公式**: `跟单保费(万) × 10,000`
- **源字段**: signed_premium_10k
- **数据处理**: 万元转换为元，缺失值填充为0
- **精度控制**: 保留2位小数

#### 2. 满期保费 (matured_premium_yuan)
- **计算公式**: `满期净保费(万) × 10,000`
- **源字段**: matured_premium_10k
- **数据处理**: 万元转换为元，缺失值填充为0
- **精度控制**: 保留2位小数

#### 3. 商业险折前保费 (commercial_premium_before_discount_yuan)
- **计算公式**: `签单保费 ÷ 商业险自主系数` (仅适用于商业保险)
- **适用条件**: 险种类 = "商业保险" 且 商业险自主系数 > 0
- **数据处理**: 非商业险或系数无效时设为0
- **特殊处理**: 自主系数为0或空值时跳过计算

### 件数类字段（单位：件）

#### 4. 保单件数 (policy_count)
- **计算公式**: `签单保费 ÷ 单均保费`
- **数据处理**: 结果四舍五入取整，最小值为0
- **异常处理**: 单均保费为0时，保单件数设为0
- **精度控制**: 整数类型

#### 5. 赔案件数 (claim_case_count)
- **计算公式**: 直接使用源字段值
- **源字段**: claim_case_count_raw (案件数)
- **数据处理**: 缺失值填充为0，转换为整数类型
- **精度控制**: 整数类型

### 赔款类字段（单位：元）

#### 6. 已报告赔款 (reported_claim_payment_yuan)
- **计算公式**: `总赔款(万) × 10,000`
- **源字段**: reported_claim_payment_10k
- **数据处理**: 万元转换为元，缺失值填充为0
- **精度控制**: 保留2位小数

### 费用类字段（单位：元）

#### 7. 费用金额 (expense_amount_yuan)
- **计算公式**: `签单保费 × 费用率`
- **源字段**: expense_ratio
- **数据处理**: 费用率缺失时设为0
- **精度控制**: 保留2位小数

### 贡献类字段（单位：元）

#### 8. 满期边际贡献额 (marginal_contribution_amount_yuan)
- **计算公式**: `满期保费 × (边际贡献率 ÷ 100)`
- **依赖字段**: matured_premium_yuan, variable_cost_ratio
- **计算逻辑**: 边际贡献率 = (1 - 变动成本率) × 100
- **数据处理**: 变动成本率缺失时，边际贡献额设为0
- **精度控制**: 保留2位小数

## 📊 使用指南

### Web界面操作流程
1. **访问系统**: 在浏览器中打开 `http://127.0.0.1:5001`
2. **上传文件**: 点击"选择文件"按钮，选择Excel文件（支持.xlsx格式）
3. **指定周序号**: 在"周序号"输入框中指定周次（1-53），默认为40
4. **开始处理**: 点击"开始上传并处理"按钮
5. **获取结果**: 
   - 自动下载：浏览器自动下载处理后的CSV文件
   - 本地访问：在项目根目录的"处理后"文件夹中查看文件

### 运行环境要求
- **Python版本**: Python 3.8+
- **核心依赖**: 
  - Flask >= 3.0.0
  - pandas >= 2.0.0
  - numpy >= 2.0.0
  - openpyxl >= 3.1.0
- **浏览器**: 支持现代浏览器（Chrome、Firefox、Safari、Edge）

### 启动方式
```bash
# 本地开发环境
python app.py

# 生产环境（使用gunicorn）
gunicorn app:app
```

### 最佳实践
1. **文件准备**: 确保Excel文件包含必要的数据字段
2. **周序号设置**: 根据实际业务需求设置正确的周序号
3. **数据验证**: 处理完成后检查输出文件的数据完整性
4. **文件管理**: 定期清理"处理后"文件夹中的历史文件
5. **错误处理**: 如遇处理失败，检查浏览器控制台和服务器日志

### 故障排除
1. **上传失败**: 检查文件格式是否为Excel(.xlsx)
2. **处理错误**: 验证Excel文件中的数据格式和字段名称
3. **下载问题**: 确保浏览器允许自动下载
4. **本地文件访问**: 检查"处理后"文件夹的读写权限
5. **服务器错误**: 查看终端输出的详细错误信息
