# 车险赔付率趋势追踪器

## 概述

基于5周历史数据追踪赔付率问题的演变轨迹,通过3层渐进式下钻定位最严重且影响最大的问题点,生成自然语言趋势分析报告。

**核心原则**: 不同层级使用不同筛选标准 - 机构层和险别层看趋势恶化程度,业务类型层看影响度。

## 何时使用

- 分析赔付率在多周内的变化趋势
- 追踪特定问题的演变(加剧/改善)
- 为领导生成易读的趋势洞察报告
- 定位需要立即干预的核心问题

**不适用于**:
- 单周快照分析(使用insurance-org-dimension-drilldown)
- 保费达成分析
- 费用率分析

## 三层下钻逻辑

### Layer 1: 机构维度 → TOP3问题机构

**筛选标准**: 综合趋势评分(越低越差)

```python
# 1. 当前赔付率状态评分(按率值指标配置)
状态分 = {
    < 60%: 95-100,  # 优秀
    60-70%: 86-94,  # 良好
    70-75%: 70-85,  # 中等
    75-80%: 40-69,  # 预警
    > 80%: 0-39     # 高危
}

# 2. 变化幅度评分
幅度分 = {
    下降 > 5%: +20,
    下降 0-5%: +10,
    持平: 0,
    上升 0-5%: -10,
    上升 5-10%: -20,
    上升 > 10%: -30
}

# 3. 连续恶化惩罚
连续分 = -10 × 连续恶化周数  # 最多-30

# 综合趋势评分
趋势分 = 状态分 + 幅度分 + 连续分
```

**排序**: 按趋势分从低到高,取最低的TOP3
**终止**: 赔付率 < 60%(优秀)的机构不纳入

### Layer 2: 业务类型维度 → 每个问题机构的TOP3问题业务类型

**筛选标准**: 影响度(赔付率 × 保费占比)

```python
影响度 = 当前周赔付率 × (业务类型保费 / 机构保费) × 100
```

**排序**: 按影响度从高到低,取TOP3
**终止**: 保费占比 < 1%的业务类型跳过

### Layer 3: 险别组合维度 → 每个问题业务类型的最差险别

**筛选标准**: 综合趋势评分(与Layer 1相同逻辑)

**排序**: 按趋势分从低到高,取最低的1个险别
**终止**: 保费占比 < 1%标记为"样本量不足"

### 趋势标签生成

```python
if 连续恶化周数 >= 3 and 当前赔付率 > 80%:
    return "🔴 严重恶化"
elif 连续恶化周数 >= 2 and 当前赔付率 > 75%:
    return "🟠 持续恶化"
elif 当前赔付率 > 80%:
    return "🟠 高危波动"
elif 5周整体变化 > 10:
    return "🟡 显著上升"
elif 5周整体变化 > 0:
    return "🟡 缓慢上升"
else:
    return "🟢 趋于改善"
```

### 核心计算
```python
def calculate_trend_score(loss_ratios):
    """计算综合趋势评分"""
    current = loss_ratios[-1]

    # 1. 状态分
    if current < 60: status_score = 97.5
    elif current < 70: status_score = 90
    elif current < 75: status_score = 77.5
    elif current < 80: status_score = 54.5
    else: status_score = 19.5

    # 2. 幅度分
    change = current - loss_ratios[-2]
    if change < -5: amplitude_score = 20
    elif change < 0: amplitude_score = 10
    elif change < 5: amplitude_score = -10
    elif change < 10: amplitude_score = -20
    else: amplitude_score = -30

    # 3. 连续恶化惩罚
    consecutive = 0
    for i in range(len(loss_ratios)-1):
        if loss_ratios[i+1] > loss_ratios[i]:
            consecutive += 1
        else:
            break
    consecutive_penalty = -10 * min(consecutive, 3)

    return status_score + amplitude_score + consecutive_penalty

def calculate_impact(loss_ratio, weight):
    """计算影响度"""
    return loss_ratio * weight * 100
```

### 自然语言生成技巧
- 用**叙述性语言**,不是表格堆砌
- **解释"为什么"**这个对象是问题
- 使用**富文本**(加粗、emoji、颜色标签)
- 提供**业务洞察**,不只是数字
- 用**疑问句引导**:"为什么说影响最大?"
- 提供**具体建议**,可操作

## 常见错误

### ❌ 所有层级都用影响度
```python
# 错误: Layer 1 也用影响度
影响度 = 机构赔付率 × 机构保费占比
```
**为什么错**: 机构层应关注趋势恶化程度,不是规模

✅ **正确**: Layer 1和3用趋势分,Layer 2用影响度

### ❌ 生成表格堆砌报告
```markdown
| 机构 | W40 | W41 | W42 | W43 | W44 |
|------|-----|-----|-----|-----|-----|
| 高新 | 71.7| 74.3| 77.8| 81.5| 84.2|
```
**为什么错**: 领导看不懂,缺乏洞察

✅ **正确**: 用自然语言叙述,解释趋势含义

### ❌ 忘记终止条件
```python
# 错误: 包含所有机构
for org in all_orgs:
    analyze(org)
```
**为什么错**: 包含健康机构,信息过载

✅ **正确**: 赔付率<60%的机构不纳入TOP3候选
